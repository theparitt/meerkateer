# Support

## Community support

The public issue tracker and discussions are not available yet. For local setup problems,
follow the troubleshooting steps on the Help page. Once the canonical repository enables
issues and discussions, search existing reports first and include version, platform,
deployment mode, redacted configuration, and reproduction steps.

Community support is best-effort. It is not an uptime or response-time commitment.

## Security

Never report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Meerkateer Cloud

Paid support channels, service hours, severity definitions, and SLA terms will be
published separately before Cloud general availability. Purchasing Cloud does not
change the Apache-2.0 license of the Community source.

## Out of scope

Maintainers cannot debug unsupported forks, leaked credentials, systems without enough
redacted diagnostic evidence, or deployments outside the published compatibility
matrix.
