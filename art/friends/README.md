# Meerkateer friends

These transparent 384×384 PNGs are small landing-page mascots derived from the visual language of
`art/logo.png`. They are optimized for UI use and included under the repository license.

| Asset | UI role | Palette and prop |
| --- | --- | --- |
| `machine-scout.png` | Machines | Turquoise/blue, binoculars |
| `heartbeat-keeper.png` | Services | Coral/red, heart medallion |
| `timeline-guide.png` | Timeline | Gold/amber, blank scroll |
| `workspace-organizer.png` | Workspaces | Mint/emerald, navy folder |
| `state-watcher.png` | States | Coral/orange, signal lantern |
| `access-guardian.png` | Access | Violet/lavender, key and shield |

Generation used the built-in image tool with `art/logo.png` as the style/character reference. The
shared prompt requested one centered, full-body mini meerkat friend in the same polished chibi
style, readable at 72 px, with large expressive eyes, rounded proportions, navy outlines, soft cel
shading, a simple silhouette, generous padding, no text, no frame, no ground, and no shadow. Each
variant then supplied the role, palette, expression, and single prop listed above. Generated alpha
PNGs were resized from 1254×1254 to 384×384 and stripped of metadata for the web bundle.
